## SectionHeader Properties 

Prop 
Type 
Description 

 title 

 string 

Section title. 

 subtitle 

 string 

Supporting text below the title. 

 children 

 ReactNode 

Actions aligned to the right. 

 badge 

 ReactNode 

Content shown next to the title. 

 tooltipContent 

 ReactNode 

Shows an info icon with this tooltip next to the title. 

 titleTooltip 

 ReactNode 

Underlines the title and shows this tooltip on it instead of an info icon. 

 isTitleLoading 

 boolean 

Replaces the title with a skeleton. 

 isSubtitleLoading 

 boolean 

Replaces the subtitle with a skeleton. 

 id 

 string 

Anchor id for linking to the section.
