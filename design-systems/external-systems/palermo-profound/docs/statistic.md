## Properties 

Prop 
Type 
Description 

 value 

 number null undefined 

The numerical value to display 

 type 

 'number' 'percentage' 

The type of statistic formatting 

 trend 

 'up' 'down' 'neutral' 

Visual trend indicator 

 showTrend 

 boolean 

Whether to show trend indicators 

 decimals 

 number 

Number of decimal places to display 

 emptyText 

 string 

Text to display when value is null/undefined 

 changeMode 

 'value' 'rank' 

How to display trend changes 

 animated 

 boolean 

Whether to animate value changes 

 suffix 

 string 

Text to append after the value 

 prefix 

 string 

Text to prepend before the value 

 disableFormatting 

 boolean 

Disable automatic number formatting 

 fixedDecimals 

 boolean 

When true, always render exactly `decimals` fraction digits (preserves trailing zeros)

 string
