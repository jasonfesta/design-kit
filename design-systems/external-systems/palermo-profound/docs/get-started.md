## Get Started 
Palermo is the Profound Design System: the components, tokens, icons, and
guidelines used to build Profound products. 

## What is Palermo? 
Palermo is a comprehensive design system built to help teams create consistent, high-quality web experiences. It provides a robust set of components, patterns, and guidelines that work seamlessly together. 
Built with React and TypeScript, Palermo emphasizes developer experience while maintaining strict standards for accessibility and performance. Our components are fully typed, well-documented, and thoroughly tested. 

## Why this site is public 
Palermo is the design system behind Profound's products. It lives inside our codebase and isn't published as a package. 
We keep this site public anyway. It's the reference and documentation our team works from every day, and a look at how we approach design: the decisions, the details, and the craft that go into what we build. 
The only way to install Palermo is to work at Profound. If obsessing over details like these sounds like you, we're hiring .
