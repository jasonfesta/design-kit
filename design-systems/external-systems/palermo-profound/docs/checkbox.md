## Properties 

Prop 
Type 
Description 

 className 

 string 

Additional CSS classes to apply to the checkbox container 

 children 

 React.ReactNode 

The content to be displayed as the checkbox label 

 color 

 string 

Custom color for the checkbox when checked (CSS color value) 

 childrenWrapperClassName 

 string 

Custom class name for the children wrapper element 

 checkboxClassName 

 string 

Custom class name for the checkbox input element 

 disableHover 

 boolean 

Disable hover state on the checkbox container 

 disablePadding 

 boolean 

Disable padding on the checkbox container 

 readOnly 

 boolean 

Prevent interaction with the checkbox while preserving appearance 

 indeterminate 

 boolean 

Show indeterminate state (shows minus icon instead of check) 

 indeterminateIcon 

 React.ReactNode 

Custom icon for the indeterminate state 

 selectedIcon 

 React.ReactNode 

Custom icon for the selected state 

 disabled 

 boolean 

Set checkbox to a disabled, unclickable state 

 checked 

 boolean 

The controlled checked state of the checkbox 

 defaultChecked 

 boolean 

The default checked state when used as an uncontrolled component 

 onCheckedChange 

 (checked: boolean) => void 

Event handler called when the checked state changes 

 required 

 boolean 

When true, indicates that the user must check the checkbox before the owning form can be submitted 

 name 

 string 

The name of the checkbox, used when submitting a form 

 value 

 string 

The value of the checkbox, used when submitting a form
