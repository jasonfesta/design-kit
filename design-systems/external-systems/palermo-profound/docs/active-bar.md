# Active Bar

Source: https://palermo.tryprofound.com/docs/active-bar

## Active Bar 
The sliding highlight behind the active item in a vertical navigation list. 

## Example 
Place it inside a relative list that sets --item-height . Move it by changing top ; the bar animates between items.
