## 3. Systems 11–20 Expansion (added 2026-11-11)

Systems 11–20 were sourced from Carbon codegen output under `//depot/google3/ux/tokens/design_systems/` (`gemini`, `ghs`, `travel`, `merchant`, `gpay`, `notebooklm`, `earth`, `hex`, `plexi`) plus the ChromeOS Jellybean library at `//depot/google3/third_party/javascript/cros_components/`. Each `tokens.css` annotates any value not present in google3 with `/* inferred */` (registry field `token_values_inferred`: `none` / `partial` / `all`).

| Need | Pick |
| :--- | :--- |
| Conversational AI / copilot shell | **`11-gemini-gem`** (drawer + borderless responses + gradient prompt pill) |
| IoT / device control, setpoints, live camera | **`12-home-ghs`** (heating / cooling / lighting semantic families) |
