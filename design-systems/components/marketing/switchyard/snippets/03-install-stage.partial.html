CLI install command

Stages a copyable terminal setup line for developer launch pages across default, copied confirmation, and multi-step deploy output states.

When to use

  • Place beneath a developer launch hero when engineers want to scaffold a local service directly from their terminal.
  • Show the three-step deploy output state when documenting push-to-live verification without dashboard screenshots.

How to apply it

  • Limit package manager options to three common runtimes so the command row stays clean and spacious.
  • Stack the idle and copied button labels inside one grid cell so copying causes zero horizontal layout shift.
  • Keep terminal output limited to four concise lines rather than crowding the block with sliders or metric widgets.
