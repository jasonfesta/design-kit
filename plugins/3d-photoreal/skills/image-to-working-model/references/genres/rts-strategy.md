# Genre Cartridge: Real-Time Strategy & Kingdom Simulation (`Age of Crowns` Dossier)

Enforce these **15 Non-Negotiable Genre Laws** whenever building a 3D Real-Time Strategy (`RTS`), City Builder, or Tactics game in Three.js.

---

## 1. The 15 Non-Negotiable RTS Laws

1. **Telephoto Isometric-Perspective Camera (`FOV = 28 deg`, `Pitch = 38 deg`, `Azimuth = 45 deg`)**: Eliminates wide-angle edge distortion while preserving true 3D height parallax for castle towers, cliffs, and arcing trebuchet boulders (`distance = 68 m` macro default, `10–15 m` close-up inspection, `148 m` strategic overview).
2. **Exact Triangle-Barycentric Terrain Height (`getHeightExactTriangle`)**: Never use bilinear heightmap interpolation (`lerp(lerp(...))`), which disagrees with triangulated terrain quads by up to `0.15 m` on slopes. Evaluate planar barycentric coordinates matching the exact quad diagonal split of `rebuildTerrainQuadDiagonals` (`<= 2.2e-14 m` raycast parity).
3. **Strict Wet-Water Predicate (`world.isWaterOrFordAt(wx, wz)`)**: Require `inRiverChannel && absD < halfWidth - 0.12 && getHeightExactTriangle(wx, wz) <= WATER_LEVEL + 0.04 && !isBridgeAt(wx, wz)` before applying wading submergence (`-0.34 m`) so units on elevated dry banks never sink into grass.
4. **Position-Hashed Smooth Normal Welding (`weldSmoothNormals`) + `22–28` Seg Catmull-Rom Lofts**: Build all human, monk, horse, sheep, deer, boar, and wolf anatomy with `catmullRomLoft` (`22–28` radial segs, `3` sub-rings/span) and `splineTube`, then run `weldSmoothNormals(geom, 68)` (`1e-4 m` position hash) while preserving existing vertex colors in `bakePartGeometry`.
5. **2-Segment Knee-Articulated Limbs, `_hullPts` Floor Clamping & Recessed Garment Shadows**: Split every human and quadruped leg into `upperLeg` + `lowerLeg` with a buried spherical knee/hock ball, precompute 50 directional hull extrema (`_hullPts`), clamp `root.position.y` every frame (and across `deathProgress = 0..1`) so `minWorldVertexY - groundY >= +0.015 m`, and build skirts/robes with `capStart: false` + `buildRecessedGarmentShadow`.
6. **Unified `world.getObstacles()` Registry + Swept-Corridor `A*` + 2-Pass Hard Depenetration**: Export every physical tree (`oaks, pines, birches` linked to `nodeId`), boulder, cliff crag, and mine from `terrain.js` via `world.getObstacles()`. Use Minkowski rounded-AABB corridor checks (`segmentHitsRoundedAABB` with `eavesPad = 0.34 m`), 3-whisker predictive feelers (`0, +-32 deg`), and a 2-pass hard depenetration solver (`_resolveWorldObstacles`) verified by a 240-tick zero-penetration torture test.
7. **`< 300 ms` LUT Procedural PBR Textures (`512x512`) + Frustum-Packed `InstancedMesh` Batching**: Synthesize tileable PBR textures using precomputed `HASH_LUT[4096]` tables (`smooth bilinear fbm2` inside ashlar blocks, never raw `hash2i` TV-static noise), batch multi-part units into shared `InstancedMesh` buckets (`150+` articulated units in `~45` draw calls), and dynamically pack static forest/foliage instances within `cameraTarget +- 72 m` (`< 450k` triangles at `60 FPS`).
8. **Instant Team-Color Silhouette Readability & Split Horse Barding**: Display crisp faction heraldry (`Royal Cobalt #1D4ED8` vs. `Crimson #DC2626`) on shields, surcoats, plumes, sheep collars, and roof pennants; split cavalry horse barding into distinct front (`chest_caparison`) and rear (`crupper_caparison`) housings so all 4 articulated equine legs remain clearly visible at `45 deg` isometric view.
9. **Task-Swapping Villager Props & Ground-Flush Furrowed Farms**: Dynamically swap villager hand meshes by task (`tool_axe -> carry_log`, `tool_pickaxe -> carry_gold_ore`, `tool_hammer`, `tool_hoe -> carry_wheat_sheaf`, `tool_fishing_net`); render farms as ground-flush (`y = +0.025 m`, `polygonOffsetFactor = -2`) dark-loam furrows with 3 crop growth stages and desynchronized off-center stooping farmers.
10. **Rising-Course Construction Scaffolding, Localized 3D V-Breaches & Lockable Gatehouses**: Render `buildProgress < 1.0` via rising stone courses inside 3D timber scaffolding; render low-HP wall/castle damage via 3D V-notched masonry breaches (`breach_notch`) and rubble piles; and raise/lower gate portcullises automatically for friendly units while supporting `[Z]` Lock Gate toggles.
11. **Additive Bonus-Damage Counter-Triangle & Couched Lance vs. Braced Pike Micro**: Implement AoE2's exact additive armor-class formula (`max(1, (A_base - D_armor) + sum(max(0, B_c - D_c))) * M_elev * M_stance`); heavy cavalry at `>= 80%` speed for `>= 1.6 s` couch lances for `1.75x` charge shockwaves unless hitting `stand_ground` pikemen whose braced `45 deg` pikes reflect `50%` charge damage.
12. **45-Degree Rotated Isometric Diamond Minimap & `< 18%` HUD Occlusion**: Rotate the minimap canvas `-45 deg` into a diamond matching the `45 deg` camera azimuth (`1:1` screen-to-minimap movement), keep total HUD occlusion `<= 18%` (`0%` central foveal clutter), and pre-decode all `PNG_DATA_URIS` portraits synchronously (`bindSafeImg`).
13. **7-Mood Modal Karplus-Strong Soundtrack & 24-Voice Spatial Foley Bus**: Synthesize plucked Renaissance lute/harp, recorder, viola da gamba, and stone-cathedral convolution reverb across 7 moods (`menu, peace, feudal_bloom, tension, battle, victory, defeat`) + 28 spatialized 3D Foley synths capped at `MAX_ACTIVE_SFX = 24` (`DEDUP_WINDOW_MS = 6`).
14. **Adaptive Rival AI Commander & Autonomous Wildlife Ecosystem**: Drive rival AI through a full Dark -> Feudal -> Castle -> Imperial build order with dynamic counter-unit scouting, while `sheep` herd/pen in `sheepfold`s, `deer` flee, `boar` retaliate/lure, `dire_wolf` packs ambush, and `shepherd_dog` companions guard villagers.
15. **Deterministic Scenario Presets (`F5–F9` / `?preset=...&warmup=...&cam=x,z,zoom`)**: Provide instant 1-click and URL query access to curated gameplay stages and close-up camera distances (`distance = 12–16`) for both human play and automated `closeup-critic` inspection.
