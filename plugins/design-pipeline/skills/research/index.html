research is Stage 1 of jason-design-agent. Weak concept runs fail because they gather interchangeable warm-beige sites and average them into mush. research solves this at the root by yielding 5 standout real-world benchmark examples specifically selected so they produce 5 unmistakably different results when translated into Nano Banana concepts—backed by inner-design craft touchstones and a cursory sweep across 19 specialist design directories.

workflow checklist

  • step 0 — url-list intake (when the user supplies urls): skip open-web discovery. Run node scripts/capture_fullpage_devtools.mjs --study-dir=<study> --urls="<pasted list>" (or --urls-file=) outside the sandbox. It slugs every url into research/sources.json, captures the entire long desktop page of every url first (@2x, tiled CDP, up to the ImageMagick ceiling), writes inspiration/manifest.json + inspiration/README.md + inspiration/<slug>-desktop-fullpage.png immediately, then runs the mobile pass. Then fan out the analysis across agents with run_workflow(ScriptPath="scripts/analyze_inspiration_workflow.py", Args={"study_dir": ..., "user_prompt": ...}) — one analyzer agent per url in parallel (research/properties/<slug>.md + research/prompts/<slug>-inspiration-prompt.md), one synthesizer (research/benchmarks.md + research/style-range.md), one adversarial verifier. Protocol: url-intake-and-multi-agent-analysis.md. Continue at step 4 with the synthesized style range.
  • step 1 — enforce chromatic & structural separation across 5-10 named style-range directions: research all provided/category-leading properties and ensure the resulting Style Range (5-10 distinct named styles) spans contrasting non-beige visual worlds (zero warm-beige/oat/cream monoculture)—for example, optic #FFFFFF & brushed steel, crisp mineral alabaster & 1px Swiss telemetry ledger, nocturnal #0A0B0E chiaroscuro, cool raw #E3E6EA concrete & architectural grid, stark #0C0C0E / #F7F8FA split monochrome, technical blueprint cobalt, and chromatic editorial studio.
  • step 2 — capture pixel-perfect full-webpage screenshots (capture_fullpage_devtools.mjs via Chrome DevTools / Playwright) + cursory 19-directory sweep: run scripts/capture_fullpage_devtools.mjs to capture the entire full-length webpage at @2x Desktop (desktop-fullpage.png 2880px wide + 4-column desktop-fullpage-contact.jpg + 2K hero/mid/lower/footer base slices) and @3x Mobile (mobile-fullpage.png 1170px wide + mobile-base-2k.png), plus fullpage-callouts.json mapping every section and callout from top to bottom. Visually inspect every capture via read_file (falling back to viewport-scrolled slices on sticky-scroll or bot-gated pages), and run a fast scan across godly.website, landdding.com, footer.design, mobbin.com, 60fps.design, beui.dev, backgrounds.supply, and fontinlogo.com.
  • step 3 — document the full-webpage 5-part anatomical & section-callout breakdown per site (research/properties/<NN>-<slug>.md): for every researched site, explicitly break down (1) header, (2) navigation, (3) every tout & callout across the entire full webpage (hero + every mid/lower callout card, bento cell, code/diff block, metric strip, and proof rail), (4) each interaction (live sandboxes, tabs, code toggles, diff sliders, workflow graphs), and (5) footer (colophon, columns, status pill, closure), alongside textural/material, designer, and frontend-developer art-direction specs and 2K base transfer plates for image-gen.
  • step 4 — compile research/benchmarks.md + named 5-10 Style Range + avoid_fonts blocklist: synthesize and name the 5-10 distinct style directions that break down the first moodboard, verify squint-test separation (zero default beige), and log proprietary/brand typefaces in avoid_fonts so google-font-selection pairs fresh live Google Fonts with each style's authentic visual energy.
