Install once in Jetski

Install either the standalone skill or the full design-kit-jig Jetski plugin (skill + jig-agent + jig-recorder). Everything is driven by jig.config.json, so your project can use any slide types, custom style names, UI/motion libraries, and optional clone service. Read INSTALL.md for the full walkthrough.

Standalone Skill (Global)

Available in every Jetski chat across all workspaces. Also downloadable as style-jig.zip.

mkdir -p ~/.gemini/config/skills
unzip -o style-jig.zip -d ~/.gemini/config/skills/
# Or one-liner on corp workstations:
bash /google/data/ro/users/jf/jfesta/www/style-jig/install.sh

Full Jetski Plugin (design-kit-jig)

Bundles style-jig, jig-agent, and jig-recorder with a valid plugin.json manifest.

mkdir -p ~/.gemini/config/plugins
unzip -o design-kit-jig-plugin.zip -d ~/.gemini/config/plugins/
# Or one-liner on corp workstations:
bash /google/data/ro/users/jf/jfesta/www/style-jig/install.sh --plugin

How it sets itself up — and reuses across projects

Do not edit boilerplate by hand. After installing, ask Jetski to set up style-jig: it inspects your package.json, asks for your slide types, libraries, styles, and optional clone source, and writes jig.config.json automatically.

Guided first-run self-setup

"Set up style-jig for my project — ask me for my slide types, UI and motion libraries, style slots, and optional clone source."

Generates jig.config.json without assuming defaults

Custom types, styles, and libraries in one shot

"Use style-jig to create a light-mode Landing and Checkout workspace with MUI + GSAP, 3 custom styles (warm-paper, swiss-grid, editorial), and no clone slot."

Runs init_style_jig.py with --domains, --styles, --no-clone, --libs

Plug in an external clone service

"Configure cloneSource in jig.config.json to use our external clone service and mount its baseline output in the clone slot."

Clean adapter slot in jig.config.json and Trace .md

Run Playback and record an MP4

"Use style-jig to play the showcase walkthrough, record a 12-second H.264 MP4, and critique the keyframes."

Captures MP4, 6 keyframes, and DOM/contrast checks

Add a 3D, shader, or mobile inspector slide

"Add an immersive 3D slide to jig.config.json and bind the right-hand drag-scrub inspector sliders to camera depth and roughness."

Auto-dims top libraries while keeping Moon/Sun and Play live

Wire a static HTML demo

"Drop the vanilla style-jig overlay onto index.html so I can switch styles, run Trace, and share a standalone Open link."

No React build step required via --vanilla

What is included in this version

Full parity with the latest Slides harness, tested end-to-end across desktop 1440px and mobile 390px.

Control What it does Hook / shortcut
Playback Toggles interactive stage motion and spawns the visible emerald autopilot cursor stepping across [data-ap] waypoints. Yields on manual click or Escape. [data-jig-play-toggle] / Esc
Record Strokeless red dot runs a 12-second showcase across styles, themes, and slides, then opens a post-take output banner with Replay and Export JSON. [data-jig-record-toggle]
Trace Builds a complete markdown spec for the active slide, style, donor variant, and standalone URL. Opens in a new tab or in-app modal when embedded. [data-jig-action="trace"]
Prompt Snapshots the live rendered stage DOM and matched CSS rules (stripping all Jig chrome), copies rich HTML + plain text, and swaps to copied to clipboard with 0px shift. [data-jig-action="prompt"]
Open Launches the active view 100% chromeless in a new window with URL state preserved. ?app=&slide=&style=&variant=&theme=&lib=
Styles & Notches 9 styles (clone through retro), 5 right-edge 16x16 donor notches with 176x124 hover preview, plus UI library and dark/light theme toggle. Alt+1 .. Alt+5
Inspector & TOC Expandable accordion Left TOC (horizontal bar on mobile) and right-hand .dk-panel drag-scrub inspector with hide/show docking. window.JigAgent
