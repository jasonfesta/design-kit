## 2. Local Zero-Blaze Scripts vs. Upstream Blaze Targets

To ensure instant execution inside `/google/data/rw/users/jf/jfesta/moodboards/` without waiting on a CitC client or Blaze daemon, all core computer-vision and evaluation pipelines are packaged directly inside [`skills/image-to-react/scripts/`](../scripts/):

1. **[`scripts/prepare-and-extract-image.py`](../../replicate-mock/scripts/prepare-and-extract-image.py)**:
   - Runs sRGB + Retina `@2x` normalization (`mockup.png`), computes `layout_metrics.json` (dominant hex palette, body container margins, horizontal section gutters, edge cuts), discovers visual clusters (`mockup_candidates_overlay.png`), and extracts non-widget media crops with 70% area-floor edge snapping (`assets.json` + `contact_sheet.png`).
2. **[`scripts/eval-image-to-react.mjs`](../scripts/eval-image-to-react.mjs)**:
   - Compiles the Golden Template React project, renders `dist/index.html` in Headless Chrome at exact `W_ref × H_ref` (hiding `#gt-inspector-host` during capture), runs the live DOM probe for collisions, overflow, text clipping, **button padding symmetry**, and **grid card equality**, and computes `s_total`, `container_deviations`, `rendered_overlay.png`, `diff_mask.png`, `side_by_side.png`, and `visual_match_audit.json`.
3. **[`scripts/lint-golden-template.mjs`](../../golden-template/scripts/lint-golden-template.mjs)**:
   - Enforces the canonical `golden-template/dating` file tree, dependencies, nomenclature rules, and `tsc --noEmit`.
4. **[`scripts/build-all-projects.mjs`](../../golden-template/scripts/build-all-projects.mjs)** & **[`scripts/verify-html-bundle.mjs`](../../golden-template/scripts/verify-html-bundle.mjs)**:
   - Builds single-file React deliverables, injects the `#gt-inspector-host` Code & Local File Inspector (`inspector-dating` experience), and verifies zero runtime/console/CORS errors.

### Optional Upstream Google3 Blaze Invocation
When running inside an active CitC client and you wish to cross-check against the upstream C++/Python `AutoRaterV1` binary directly:

```bash
/google/bin/releases/arca9-local-blaze-cli/blaze-for-agents run \
  //prototypes/projects/agentic_design_loop/skills/visual_matcher/scripts:evaluate_match -- \
  --workspace_dir=/tmp/img2react_work \
  --reference_image=/tmp/img2react_work/mockup.png \
  --candidate_image=/tmp/img2react_work/rendered.png \
  --candidate_html=/path/to/moodboard/projects/01-website-brand/dist/index.html \
  --output_json=/tmp/img2react_work/visual_match_audit_blaze.json \
  --output_diff_mask=/tmp/img2react_work/diff_mask_blaze.png
```
