## 1. 4K Grid Source Verification & Geometry Audit

Before planning interactions or writing React components, we verified both 4K sheets in [`websites/virel/`](./nano-banana-2-cleanup/websites/virel):
1. **`input.png` (`4096 × 2458`, true `5:3` 4K Grid Sheet — `819.2 × 2458` / `1:3.000` per column)**:
   - Contains all 5 full-length pages (`Home`, `Collection`, `Gesture`, `Our story`, `Care`) with **undistorted 1:3 vertical proportions**, crisp gold-embossed `VIREL` hardware/leather stamps, and clean English editorial copy.
2. **`output.png` (`4096 × 4096`, FAL square geometry failure)**:
   - As documented in `metadata.json`, FAL returned a `1:1` square sheet (`39.99%` aspect ratio drift) that vertically stretched photographs and garbled raster text into gibberish (`"Commee the Olorts"`, `"The Sinas"`, `"VIREE"`), which caused double-rendered ghost text underneath live HTML typography when raw crops were used.
3. **4K Asset Strategy**:
   - Use the **true 5:3 4K image (`input.png`)** + **`2x` Retina `gempix-1` de-dithered/text-stripped photographic plates** (and fix Page 2's *"Make room for Cove"* plate via `gempix-1` so the model carries the cognac **Cove** bucket bag rather than Gesture, per `websites/virel/prompt.md`) while keeping the `1000 × 3000` canonical 1:3 layout coordinates locked for visual evaluation (`s_total >= 0.93+`).
