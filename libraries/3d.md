# 3D, WebGL / WebGPU & 3D asset encoding

Engines, React bindings, helpers, physics, post-processing, text, shaders, **and the asset pipeline** ("3D encodes": Draco, meshopt, KTX2/Basis, glTF tooling, Gaussian splats). Pairs with the `3d-photoreal` and `games` plugins.

- **Kit default:** `three` (WebGL2 + `WebGPURenderer`/TSL) + `@react-three/fiber` + `@react-three/drei` inside React; ship assets as **glTF/GLB, meshopt-compressed geometry, KTX2 (UASTC/ETC1S) textures**.
- `★★★` industry standard · `★★` solid · `★` niche/young. Stars approximate (late 2026).

**Count: 84 entries.**

## 6. 3D asset encoding & pipeline ("3D encodes")

> **Recommended pipeline:** export GLB from Blender → `gltf-transform optimize in.glb out.glb --compress meshopt --texture-compress ktx2` (or `webp` for small sites) → `npx gltfjsx out.glb --types` → load with drei `useGLTF` (auto-wires `MeshoptDecoder`, `DRACOLoader`, `KTX2Loader` with `useGLTF.setDecoderPath`). Budget: <2 MB hero GLB, ≤2k textures, instanced repeats.

## Decision rubric
| Need | Pick |
| :--- | :--- |
| 3D in a React page | R3F + drei (+postprocessing) |
| Designer authored, quick | Spline (watch bundle ~1 MB runtime) |
| Product viewer / AR, no code | `<model-viewer>` |
| Globe | `cobe` (decorative) / `react-globe.gl` (data) |
| Tiny shader effect | OGL or Paper Shaders |
| Typed GPU compute | TypeGPU or three TSL compute |
| Physics | Rapier (3D), Matter.js (2D) |
| Ship assets | gltf-transform → meshopt + KTX2 → gltfjsx |
| Photoreal real-world / AI-world splats (WebGL2/WebGPU) | SuperSplat → `.sog` / `.spz` → `@sparkjsdev/spark` (WebGL2) or Three.js `r186+` `GaussianSplat` (WebGPU) |
| Feed-forward surface-aligned 3DGS (single photo, portrait in scene, multi-view, 360° pano) | `infinisplat-3dgs` skill (`zju3dv/InfiniSplat` v1–v3 GSNorm + `scripts/infinisplat_bake.py` WebGL2 EWA baker) |
| Single photo → 360° modular linear-HDR PBR WebGL2 environment + Design Kit Jig | `photo-to-3d-environment` skill (`plugins/3d-photoreal/skills/photo-to-3d-environment/`) |
